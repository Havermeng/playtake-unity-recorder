# PlayTake — запись видео в Unity

Окно **Window → PlayTake → Recorder** записывает Game в MP4, с игровым звуком по желанию. Запуск и остановка: кнопками или **Ctrl+Shift+F10**.

## Установка

Требуется Windows, Unity6000.3+, внешний FFmpeg. Проверено на Unity6000.3.3f1/HDRP17.3/Windows11. Другие версии и рендеры пока не проверены. FFmpeg не включён: скачай через https://ffmpeg.org/download.html и укажи `ffmpeg.exe` в окне.

Выбери один способ:

- Package Manager → + → Install package from Git URL: `https://github.com/Havermeng/playtake-unity-recorder.git#v1.0.0-preview.1`.
- Либо скачай `.unitypackage` из Releases и импортируй все файлы в `Assets/PlayTake`.
- Либо установи `.tgz` через Package Manager → Install package from tarball.

Не устанавливай несколько вариантов одновременно. Пакет: `com.havermeng.playtake`.

## Использование

1. Открой Window → PlayTake → Recorder.
2. Выбери папку, разрешение720p/1080p/1440p или своё, FPS24/30/60, качествоCQ. МеньшеCQ — выше качество и больше файл.
3. NVIDIA NVENC кодирует на видеокарте. Если подходящей NVIDIA нет, выключи галочку дляCPU H.264.
4. Включи Play и держи вкладку Game видимой. Нажми Start recording или Ctrl+Shift+F10.
5. Останови тем же сочетанием либо Stop and save. Дождись Saved. По умолчанию видео в папке Видео/Unity.

Записывается текущая игровая камера вместе с интерфейсом, свободная камера не добавляется. Звук берётся из Unity AudioListener: без микрофона и других приложений. При отсутствии данных слушателя получится видео без звука с уведомлением.

60FPS в настройке файла не гарантирует60уникальных кадров: при перегрузке повторяется предыдущий кадр, длительность соответствует реальному времени. Счётчики сохраняются рядом в `.mp4.recording.json`. Начни с1080p30 или720p30. При другом соотношении сторон Game добавляются чёрные поля.

Выход изPlay автоматически завершает запись. Изменение размераGame её останавливает; после изменения начни новую. Пока идёт запись, не меняй исходники. При ошибке временные `.video.mp4` и `.audio.wav` сохраняются для восстановления, подробности в окне иConsole.

Это предварительный релиз: короткие тесты выполнены, долгие записи, точная воспринимаемая синхронизация звука и смена сцен ещё не проверены.

## Удаление

УстановкаUPM: Package Manager → PlayTake → Remove. Установкаunitypackage: после остановки записи удали только `Assets/PlayTake`. Снятые видео остаются в выбранной папке. При необходимости настройка очищается `EditorPrefs.DeleteKey("PlayTake.Options.v1")`.
