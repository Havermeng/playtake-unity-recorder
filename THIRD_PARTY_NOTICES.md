# External software

No third-party binaries or assets are bundled.

- Unity Editor and Unity APIs are provided by the user's installation, under Unity's terms: https://unity.com/legal .
- FFmpeg is a separately installed dependency: https://ffmpeg.org/ . Its license depends on the build configuration (LGPL/GPL and enabled components). This project does not redistribute FFmpeg.
- NVIDIA NVENC requires NVIDIA hardware/drivers and an FFmpeg build with support. No NVIDIA binaries are included.

PlayTake is not affiliated with or endorsed by these projects or companies.
